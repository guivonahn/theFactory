# Menu bar popover

Mode: Operate. This is a narrow native companion to the established terminal visualizer.

## Direction contract

THESIS: A glance into the same little factory while the user works elsewhere.

OWN-WORLD: Native macOS typography, popover chrome, separators and controls. Existing cyan, purple, green, yellow, red and blue agent identities appear on the workers. Follow system appearance.

STORY: Click the factory, recognize the session, see observed plan progress and which agents are working, click away to return to work.

FIRST VIEWPORT: Without a working session, a 380-point popover contains only theFactory, Idle, an animated snoozing crew and one Start work button. Start work opens the existing configuration form; Back returns home. Running sessions retain the compact title and selector, objective, progress, 126-point factory floor and named-agent rows. New opens another session configuration. Configuration and monitoring retain the launch-at-login and Quit footer. No main window or Dock icon.

CONFIGURATION: A compact New session header with a back chevron leads into a native Task / Agents / Options segmented control. Task gives the directory, a 140-point prompt and aligned profile/execution rows. Agents shows the shared model and all seven role overrides together. Options uses grouped native switches for output, workflow and permissions. A small persistent launch bar keeps Start in Terminal at the trailing edge. All pages edit the same session draft; there is no nested disclosure tree or repeated introduction.

MODEL SELECTION: Shared and individual model controls open a native searchable list inside the same popover. Read the full OpenCode catalog for the chosen project and include configured Coarena aliases, grouped first. Preserve current selections and offer profile/shared inheritance. Search filters model or provider names, Refresh reloads the catalog, and Use model confirms the highlighted row. Returning without confirmation keeps the prior value. Loading and partial/unavailable catalogs remain explicit; no hard-coded preset list is presented as the full catalog.

FORM: Precisely specified local extension; no concept seed. Signature interaction: idle workers sleep with closed eyes, gentle breathing and floating z marks; their machinery stays still. Active workers retain their original movements. Animate only while open, respect Reduce Motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Truth and limits

Percentages reuse the CLI's completed-step calculation including its final overview. With no plan, show indeterminate progress. Distinct workers with the same role retain distinct rows. Ignore dead or stale publishers. Already running CLI processes must restart once to publish. The launcher starts a fresh task automatically through a private typed JSON request; prompts are never shell source. Session settings apply before launch, as explicitly chosen by the user. Match a launched session by request ID before switching the monitor to it.
